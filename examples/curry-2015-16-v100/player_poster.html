C01 / fact

库里的全票赛季是二〇一五至一六赛季。Marc Stein 当年的报道确认，他获得全部一百三十一张第一选票，勇士常规赛七十三胜九负；这是奖项与战绩背景，并不自动证明他在篮球每个方面都优于所有人。

[EXT_STEIN]
C02 / fact

最值得强调的是高产与高效同时出现：库里出战79场，场均34.18分钟得到30.06分，真实命中率为66.9%，高出同季联盟整体12.82个百分点。真实命中率综合考虑两分、三分与罚球，这个差距比单看场均得分更能说明他的得分质量。

[P_BASE][T_BASE]
C03 / inference

这组表现支持把他定位为以投射为主要武器的高负荷进攻核心。效率优势不是靠减少任务换来的，但这里比较的是联盟整体，没有消除位置、队友和出手机会难度的差异。

使用率描述结束进攻机会的比例，不是持球时间；未作角色和投篮难度校正。

[P_ADV][P_BASE][T_BASE]
C04 / fact

库里的三分出手达到886次，占全部投篮55.4%，命中率仍为45.4%；有效命中率达到63.0%。有效命中率把三分比两分多得的分计入，却不含罚球，因此它说明他的运动战投篮本身就很有效率。

[P_BASE]
C05 / fact

Stein 的报道还指出，库里该季投进四百零二记三分，打破自己此前保持的单季纪录。报道把投射纪录与历史性战绩联系起来；本研究接受这些背景事实，但不把纪录数量直接换算成对手被牵制的回合数。

[EXT_STEIN]
C06 / inference

他的进攻价值不能缩减为站定接球投篮。追踪表覆盖79场，场均持球急停出手8.80次、有效命中率60.8%；接球投篮场均5.20次、有效命中率68.2%。两种机会都能得分，让球队有理由在持球发起和接应终结之间切换他的任务。

两类机会的位置与难度不同，不能据有效命中率直接比较能力；追踪表自身GP均为79，见原表。

[P_BASE][TR_PULL][TR_CATCH]
C07 / fact

库里场均6.67次助攻、3.32次失误，助攻失误比2.01；追踪记录场均12.60次潜在助攻与8.00次突破。潜在助攻指传球后队友出手的机会记录，它提醒读者：实际助攻还受队友是否投进影响，但也不能把所有潜在助攻都当成他独立创造的空位。

[P_BASE][TR_PASS][TR_DRIVE]
C08 / fact

全部运动战命中中，46.6%被记为受助攻，53.4%没有被记为受助攻；三分命中中受助攻比例为56.0%。这支持他既能利用队友传球终结、也能完成未记助攻进球的角色描述，不能据此把每个未受助攻命中都叫单打，或把受助攻比例叫接球投篮命中率。

[P_SCORE]
C09 / inference

从这些记录出发，更合理的使用建议是让库里在持球进攻后继续参与接应，而非要求他承担所有传球发起。若另一名队友能在他交球后及时处理球，接球投射就能成为下一轮进攻的选择；能否进一步形成持续跑动牵制，仍要核验实际防守反应。

没有实际观看并登记逐回合录像；牵制强度和交球后跑位效果尚未量化。

[P_SCORE][TR_CATCH][TR_PULL]
C10 / inference

按出场至少40场、总分钟至少1000、使用率至少25%、助攻率至少30%的统一规则，本次形成12人的高负荷组织核心样本。库里每75回合得到30.83分，组内中位数23.70分；真实命中率66.9%，组内中位数55.7%。同一回合尺度的比较更直接地支持他的得分优势。

筛选是统计角色代理；未匹配队友、战术、对手和投篮难度。

[P_BASE][P_ADV][P_100][P_SCORE]
C11 / inference

反向证据也应保留：库里每75回合助攻6.82次，低于组内中位数7.54次；助攻失误比2.01，也低于中位数2.18。非受助攻命中占比53.4%，低于中位数71.0%。因此，这个赛季不宜被描述为所有进攻都由他独自组织完成，更适合解释为得分主导、同时参与多人配合的核心。

助攻和受助攻结构不等于传球能力排名，也不能完整计量无球帮助。

[P_100][P_BASE][P_ADV][P_SCORE]
C12 / fact

放宽角色门槛后样本为19人，收紧后为10人，库里的真实命中率统计百分位分别为97.37和95.00，得分百分位也分别为97.37和95.00。得分与效率的突出方向没有因门槛变化而消失；这些百分位描述本次样本位置，不是综合能力分。

[P_BASE][P_ADV][P_100][P_SCORE]
C13 / fact

真正的在场与不在场比较显示：库里在场时勇士每百回合得117.50分、失99.80分，净效率为17.70；不在场时得102.00分、失107.40分，净效率为−5.40。净效率差为23.10，进攻效率差为15.50，这说明两组阵容表现差异很大。

[P_ONOFF]
C14 / inference

勇士的整体助攻率为68.0%，三分出手占比36.2%，每百回合得113.50分。这提供了传球与外线出手较多的球队背景，支持围绕库里的持球和接应安排多人分工；但球队整体数据不足以单独证明某一种具体战术造成了这些结果。

球队助攻率不等于传球次数或战术名称；未核验具体阵容与配合录像。

[T_ADV][T_BASE]
C15 / inference

在场与不在场差值不能解释成库里个人每百回合净贡献，也不能把在场防守失分直接当作他的防守能力。库里场均2.14次抢断描述了夺回球权的事件，却没有回答他面对强壮持球者、换防或弱侧协防时的全部表现。

队友、对手、轮换和比赛状态未调整；缺少个人对位与录像证据。

C16 / inference

Basketball-Reference 的BPM为+11.9，其中进攻分量+10.3、防守分量+1.6；VORP为9.5。BPM使用技术统计和球队背景估计相对平均球员的每百回合表现，VORP再结合出勤与替补基准；二者与高效得分的方向一致，但并非两份相互独立的证明。

BPM不是纯阵容回归；DBPM不能改名为个人防守评分；VORP不是实际多赢场次。

C19 / inference

综合来看，这一季最有说服力的优势是：承担较多得分任务时，库里仍保持很高效率，而且持球急停与接球投射都能参与进攻。合适的配置是能处理后续传球的队友、可靠的掩护和覆盖防守对位的阵容；代价是多人配合需要时机与球权协调，不能简单复制出手量就期待复制结果。

配套条件是战术使用假设，不是已验证的阵容因果结论。
