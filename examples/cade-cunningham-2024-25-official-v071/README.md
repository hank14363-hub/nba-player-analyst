## 投篮分布动效升级

球场去掉多余两侧留白，保持全场等比例和所有后场出手。命中采用低饱和青绿圆点，未中采用玫瑰色叉，图例与点击高亮更清楚。图表进入视口或筛选后，每个可见点位错落显现；点击事件用圆环突出其真实位置。

“逐次点亮”按日期、比赛、节次、比赛剩余时钟和事件ID排序，支持暂停/继续、恢复总览及三档速度；播放间隔经过压缩，点位动画仅表示事件顺序。建议先筛选单场。未播放事件保留淡色背景，统计始终按完整筛选样本计算，回放进度单列。

离开球场、切到后台、打印或改变减少动画设置会暂停；切换筛选清除旧回放。减少动画时不播放入场或扩散动效，仍可逐次更新静态高亮。关闭JS保留完整静态图。

shot-animation-preview.gif是浏览器中真实图表交互的效果预览，不是比赛录像。shot_motion_validation.json记录逐点入场、原始时序、暂停/继续、筛选取消、空样本、键盘、完整球场、静态退化与打印恢复检查。长文、claims、NBA数据、来源和长图未改；本轮只更新研究册。
