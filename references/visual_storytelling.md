# 图文叙事

让图解释判断：每张图说明读者问题、分母/单位、最值得关注的结果和结论边界。图题与相邻段落呼应，图注引用来源。不要用照片数量或重复图形伪装证据增加。

研究册十类候选图：efficiency（TS与联盟）、shot_mix（两/三分出手）、scoring_mix（两分/三分/罚球得分）、creation（每75回合得分/助攻/失误）、assisted（命中球受助攻）、team_context（在场与全队背景，不相减）、onoff（真正On与Off）、tracking（接球/急停有效命中率）。新增 shot_locations（全部真实投篮散点）、shot_zones（官方区域分母与命中结果），口径见 shot_locations.md。只有有匹配数据的图会生成。book_manifest.json.chart_evidence 保存指标和来源。

正文图片语法（单独一行）：

```markdown
![三分只是部分出手，图中分母不含罚球。[P_BASE]](charts/shot_mix.svg)
```

渲染器只嵌入本次生成的 charts 文件。Markdown 文件可与 charts 文件夹一起阅读；单文件 HTML 会内嵌 SVG。对证据丰富的长文，通常安排四至六张正文图，每图紧邻相关解读；这是阅读目标，不是强制补满数量。相同图在概览和完整正文出现时，说明它是重复展示，不能计为不同证据。

缺失块应说清“缺什么、因此不能判断什么、下一步从哪里补”。不把缺失图换成没有数据的雷达图或球场热区。战术示意若另行制作，标明建议/假设，不能伪装成真实回合截图。

保持现有球队主题、明暗层次和窄屏布局；数值轴从零起，比例/单位一致。在独立 SVG 中保留赛季、来源和合成样本声明。PNG 导出后查看实际成图，不能只用文件存在作为视觉验证。

研究册与长图使用独立的浅/深色图表体系。适度照片、GIF、动效和来源组织见 [editorial_media.md](editorial_media.md)；不以素材数量代替证据丰富度，历史照片不充当本赛季录像。
