# 高阶数据的数值百分位

新运行的 `run_analysis.py` 默认启用 `--advanced-percentiles`，可用 `--no-advanced-percentiles` 关闭。旧请求没有此字段时不追加入库指标，保持既有研究册与长图的确定性复算。

读取 `analysis.percentile_context` 或同内容的 `advanced_percentiles.json`。每项包括原始值、有效N、字段缺失人数、严格低于人数、同值人数与公式；每组记录纳入身份、来源、筛选门槛及排除原因。正文引用 `PCTL_<原指标ID>`，样本数引用相同ID加 `_N`；原始值继续使用原指标。原始值、百分位与人数须分别登记numeric_facts。已计算的来源组应有正文解读，不能只摆图。

## 方法与方向

`100 × (严格低于目标人数 + 0.5 × 同值人数) / N`。包含目标；同值同分，极值不强行写成0或100；保留提供者原表精度，不用上游排名列。至少8个有效值且目标进入同一纳入样本才计算。缺失字段不补零，逐项N可能不同。

所有轴均按**数值越高百分位越高**；失误、球队防守失分等高值不代表更好，使用率和节奏主要描述职责与环境。全位置分布与既有同角色百分位分开。它不是个人能力、置信概率、统计显著性或综合实力排名，也不跨模型相加。

## 支持的来源与范围

| 来源 | 纳入规则 | 边界 |
|---|---|---|
| NBA | 匹配同季/同比赛类型完整官方联盟基础与高阶表；GP≥20且总MIN≥500 | Advanced可能返回场均分钟，门槛只用基础总分钟；TS/eFG和助攻失误比用基础总量重算；在场效率是球队背景 |
| BR | 完整保留的Advanced HTML原表；GP≥20且提供者总MIN≥500 | 按唯一BR身份去重，转会球员只留唯一TOT或多队合计；BPM/攻防分量、VORP、WS/攻防份额/WS48及PER等分别计算；不能用NBA分布替代 |
| LEBRON | 同季转引原表，参考GP≥20/MIN≥500，姓名/NBA ID和总分钟匹配 | 不声称转引覆盖所有联盟球员；未通过行保留排除原因 |
| Actual EPM | 合法离线导出逐行按现有导入契约重建；参考GP≥20/MIN≥500，完整姓名/NBA ID/GP/MIN和分量核验 | 只比较通过核验的导出子样本；没有足够通过者继续缺失，不放宽精度以凑人数 |
| DARKO | 同赛季、同一明确历史日期完整页面样本 | 生涯加权预测，未按单季GP/MIN筛选，不与整季回顾混合 |
| 历史EPM | 已审查原CSV内同赛季、同上游来源的唯一NBA ID记录 | 仅归档数值分布，记录日期可能不齐；无可核验GP/MIN，不假装做出勤筛选 |

原始文件应与归档行及来源摘要一致；研究册验证会从保留的BR/LEBRON/DARKO原文件或历史CSV重放，拒绝重新自哈希的删行样本。未接入模型、仅有单球员记录、球队效力段、样本过小、字段缺失和范围不一致均明确说明。当前Sumitro等其他适配器不能冒充已支持重放的BR HTML原表。单队On/Off不能产生联盟百分位。

## 给已有历史EPM研究补分布

```text
python <SKILL_DIR>/scripts/prepare_percentiles.py --run-dir <已有历史EPM研究目录> --out <新准备目录>
python <SKILL_DIR>/scripts/run_analysis.py --input <新准备目录>/data_bundle.json --player-id <ID> --season <YYYY-YY> --out <新研究目录>
```

准备步骤只读已保留的原CSV，不联网。随后按新指标更新正文、claims、来源及研究册；已有文稿和影像可复用，但不要复制旧analysis覆盖新复算结果。

历史百分位的正文、图表与claims必须就近保留“口径待核验”，说明Kaggle转引、目标日期、样本日期范围不齐、无GP/MIN门槛和估计类型/比赛范围未核实。不得称作同日预测、整季Actual或联盟能力百分位。原始日期与分量核验不证明模型定义或数据授权。

## 六轴画像与第一名特效

`book_content.percentile_presentation` 可设 `radar` 或 `bars`；无此字段的旧研究册保持原呈现。新模板在已有百分位数据时预选radar。雷达仅纳入NBA职责与效率六项、BR模型与出勤六项；每张图的六轴都须有完整同一纳入样本、相同N且字段缺失为0，原始值与登记百分位一致，否则整张省略，保留下方数据表。历史EPM日期与范围待核验，不进入雷达。

虚线P50只是一条百分位刻度参考线，不代表原值均值；外圈仅表示较高数值，模型输入重叠、累计量受出勤影响，不能跨来源比较面积或合成评分。图片复用已登记且授权允许的本地球员影像，保留日期、署名、许可及来源。

新请求随默认百分位开启 `stat_leaders`；旧请求没有此字段不补写。`stat_leaders.py` 从NBA完整同赛季/比赛类型基础与高阶原表，或BR完整常规赛Advanced原页独立核验单项最大值。BR按唯一身份保留唯一多队合计；不设置雷达的出勤门槛。原始字段须全表无缺失，目标原值匹配；同值按上游公布精度并列。仅接近P100、导出子样本、单球员或混合日期历史EPM均不足以标联盟第一。NBA球队防守失分和失误比率不加荣誉高亮；本功能没有引入官方资格排行榜。

结果写入 `analysis.stat_leader_context`，名次、同值人数、完整联盟人数分别登记 `STAT_LEADER_<原指标ID>_RANK/TIES/N`。正文和claims引用原值及登记指标，说明来源/赛季/比赛类型和分母；渲染时确定性复算。第一名是该完整来源表的单项数值位置，不是综合实力排名。雷达与完整联盟人数不同须分别说明。

特效含金色星标、柔光、有限扩散光圈及说明卡；支持重播与减少动画偏好，无持续闪烁。原始表可展开，单文件仍离线可读；直接定位 `#radar-panel-bref` 可打开BR页签。完整检查记录见 `documentation/validation_v0812.md`。


v0.8.13将已核验第一的说明提升为主视觉名次卡，直接引用登记原值、名次、完整联盟N及同值人数；不以雷达N替换联盟N。默认先选带该卡的页签，明确页签锚点优先。人物轮廓字、环形短刻线和扫光均为装饰，不增加统计维度或改变顶点坐标。动画一次完成后停止，减少动画偏好、页面隐藏、无脚本及打印保留可读状态。
