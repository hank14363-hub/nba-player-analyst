# v0.5.0 升级说明

在 v0.4.0 官方受助攻、真实 On/Off、追踪指标与图文基础上，完成上一轮三个优先方向：

- 选择表补抓：新数据包＋逐表修复日志，未选表/来源保持一致；失败可从新包继续。禁止静默替换已有行，禁止真实与合成数据混合。
- 真实投篮图：官方全部 FGA 事件，四项总计核验；全场散点保留远距投篮，区域统计显示命中/出手和少样本。来源标签冲突单列，原始行不改。
- 录像流程：空模板、实际观察者、比赛/视频双时钟、来源、替代解释、取样依据及 observation_ids 校验。未自动看录像，不给个人防守评分。

坎宁安案例仍为2024–25常规赛：1457次出手、684次命中、418次三分出手、149次三分命中、70场，与基础统计完全一致。发现一条“Above the Break 3 / 2PT Field Goal”标签冲突，事件 0022400881 / 637；区域表单列一条冲突，不把它改成三分。全文3153汉字、19条结论、71次数值登记；研究册10类图、正文8处嵌图；结论长图保留原六图契约。

实际网络补抓受助攻与投篮响应，受助攻表成功；投篮首次被严格标签检查拒绝，保留原输入。确认官方单条标签冲突后，新增可见冲突分组，用真实缓存重试成功。未选表、来源和原抓取日期保留。不会把一次成功写成服务永久可用。

独立试用发现并修正：主输入契约遗漏新表；--input 下联网选项被静默忽略；只想导出图时缺少入口。现补全主表文档，明确拒绝该参数组合，提供 render_shot_charts.py；无需先写完整文章即可导出图和来源清单。

历史入口重命名为 SKILL.v0.3.1.md，内容保留，避免主技能和历史技能重复发现。数据结构仍为0.1.0，研究册内容为0.2.0、长图内容为0.3.0；发布版号与数据契约不混用。旧证据包未包含投篮表时不增插空指标，仍可按原契约复算；加入新事件后应新建研究目录。

验证结果见 documentation/validation_v05.md。浏览器与数据检查证明可复算和布局可读，不能证明战术建议或个人能力结论。
