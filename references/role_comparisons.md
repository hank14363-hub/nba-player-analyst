# 同角色比较与个性化封面 · v0.8.0

## 先核验已有表，不从旧缺失提示推断当前数据

先检查 data_bundle.json 的全联盟表是否仍被保留。`--comparisons` 是可选、可复算扩展；不会新增 NBA 网络请求，也不会自动抓取第三方影响力。

```text
python <SKILL_DIR>/scripts/run_analysis.py --player-id <ID> --season <YYYY-YY> --input <完整数据包> --comparisons --out <新目录>
```

在线运行也可加 `--comparisons`。旧 request 未启用该参数时保持原指标集合，历史案例可继续复算。不能手改 analysis.json 数值；补比较需要重新执行 analyze 或 run_analysis 并审阅正文、claims 与派生文件。

四张必需表：player_base / P_BASE、player_advanced / P_ADV、player_per100 / P_100、player_scoring / P_SCORE。当前自动比较仅接受登记完整 NBA 参数、无子样本过滤、来源行数与 SHA256 摘要匹配的官方表。核验同季同比赛类型、四表身份完全覆盖且无重复球员，季节合计 GP、TEAM_COUNT 与受助攻 FGA/FGM 一致；TS 统一由基础总量复算并核对来源。不同球队段必须先有明确聚合方法，不能悄悄选最后一行。

先用 GP≥40、MIN≥1000 作为稳定轮换规则。这是研究门槛，不是显著性阈值；季后赛通常不满足，不混入常规赛凑样本。任何达到出勤门槛的球员有必要字段缺失，停止“完整样本”比较并报告原因，不悄悄排除后画雷达。目标未达门槛、球队段过滤或同组少于八人时，不强行降低门槛；可另做明确标为小样本的描述表。

自动功能角色按下列优先顺序选择：高负荷组织核心（USG≥25%、AST%≥30%），篮板职责（OREB%≥8%、DREB%≥18%），三分职责（三分出手占比≥45%、三分出手≥200），高使用率终结者（USG≥25%），其余稳定轮换。角色是统计代理，不能当成核验过的场上位置或完整打法。纳入名单必须全部公开，按姓名排列；来源球队标签不代表整季效力归属。

## 百分位是统计画像，不能直接称能力

当前六条公共进攻画像轴：PTS/75、AST/75、TS%、AST:TOV、非受助攻命中占比、TOV/75。它不是完整篮球能力模型，也不包含个人防守。保存实际值、中位数、N、原始名单、数据摘要和方向；失误轴反向，其余按读数升序。自主终结高占比描述任务，不能当作必然优势。

经验百分位＝100×（严格更差人数＋0.5×同值人数）/N，包含本球员。相同值同位；不采用服务商全联盟原始排名。不能求雷达面积、平均百分位或总分，不能宣称超过某比例球员的“真实能力”。小组百分位较粗，展示一位小数只是读数格式，不表示估计精度。

高负荷组织核心额外比较宽口径（USG≥23%、AST%≥25%）和严格口径（USG≥28%、AST%≥30%）；其余角色以 GP≥50、MIN≥1500 检查出勤敏感性，仅当目标仍在组内且人数足够时展示。门槛变化是反证检查；解释稳定方向和变化的结论，不能挑最有利版本作封面。新纳入规则需另建方法并验证，不能在文案里换规则而仍使用旧轴。

比较上下文保存于 analysis.comparison_context。book_contract 同时复算指标、名单、敏感性与坐标；修改名单或轴数据会被拒绝。来源索引复用原始表的采集时间；本轮计算时间不冒充新抓取时间。

## 封面四项依据球员职责选择

研究册与结论长图共享 core_metrics.py。默认按功能职责选择四项可用指标；缺少追踪时从已核验基础/回合指标回退，薄样本明确显示 N/A。不得把抢断、盖帽和团队失分重命名成个人防守优势或评分。

更好的最终成果应由作者在 book_content.json 配置四项 `core_metrics`，每项含 metric_id、label、note、claim_ids。metric 必须 status=ok，四项不得重复，至少一条指定 claim 确实登记该指标。标签与说明不直接手填统计数字，读数从 analysis 取值。说明该项为什么能代表职责、分母是什么，并在相邻正文保留效率与失误等代价。它是个性化阅读入口，不是只挑四个好看的数字。

射手默认更关注三分命中率、三分出手占比、接球 eFG 与 TS；篮板职责更关注前后场篮板率、REB/75 与 TS；高负荷组织者关注 AST%、自主终结结构、突破次数与 PTS/75。这些选择仅表示职责线索，自动预设不证明对应读数具备比较优势。人工选择优势项时须有明确基准与反证。

## 热区与影响力

完整坐标通过 FGA/FGM/3PA/3PM 核验后，可画五英尺网格真实出手频次热区。格子为精确计数，颜色线性对应出手数，不平滑、不凭空填点；悬停保留命中数。近端半场不含四个远端事件时明确说明，全部事件仍在交互球场。频次不需要联盟基准；相对效率热区需要同口径联盟分母、区域映射与足够样本，目前未提供。

NBA PIE 使用 Advanced 来源原值，是技术统计事件贡献份额；可加同角色中位数，但不能当作调整过阵容、对手的每百回合净贡献。不要称它为 EPM、个人防守分或综合能力。On/Off 的描述性限制保持不变。

第三方影响力先核验提供者、实际值/预测值、历史截止日、比赛类型、模型版本、分钟与访问边界。公开页面允许读取不等于页面中的历史数值可取得。订阅或身份匿名限制时不提取受限脚本数据；当前快照或历史预测不能替代整季实际值。v0.8.0 坎宁安案例只核验 EPM 公开历史页面的访问范围，没有导入 EPM 数值，保留 impact_access_audit.json。未取得的数据按实际缺口呈现；缺失文案根据现有上下文生成，不再写死“没有坐标/没有比较样本”。
