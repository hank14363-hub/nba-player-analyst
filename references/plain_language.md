# 常用术语：说清楚，但不说错

供改写时查阅，不是自动生成球员评价的词典。以下解释沿用本包 `metrics.md` 的定义；公式、数据来源和数值均不修改。

| 术语 | 面向读者的说法 | 不能换成什么 |
|---|---|---|
| 真实命中率 TS% | 把两分、三分和罚球一起考虑的得分效率指标 | 不是投篮命中率，也不是综合实力 |
| 相对真实命中率 rTS | 真实命中率比同赛季、同比赛类型的基准高或低多少个百分点 | 不把百分点写成相对增长百分比；合成基准不叫NBA平均 |
| 有效命中率 eFG% | 考虑三分球得分更高后的投篮效率，不包含罚球 | 不是TS，也不是进攻全貌 |
| 使用率 USG% | 球员在场时，以出手、罚球或失误结束球队进攻机会的估计比例 | 不是持球时间或触球次数占比，也不说明传球好坏 |
| 助攻率 AST% | 球员在场时，队友投进的球中有多少由他助攻的估计比例 | 不是每次传球变成助攻的概率 |
| 每75回合数据 | 放在同样的球队进攻回合尺度上看得分、助攻等产出 | 不是每场75次个人出手，也不消除全部角色差异 |
| 助攻失误比 | 助攻次数除以失误次数 | 不能单独代表传球难度或组织水平 |
| 罚球出手比 | 罚球出手数除以投篮出手数 | 不是造犯规成功率，也不是罚球命中率 |
| 受助攻命中比例 | 已经投进的球中，有多少被记为队友助攻 | 不是全部接球投篮出手或其命中率 |
| 非受助攻命中 | 这次投进没有被记为队友助攻 | 不等于单打，也不能自动说明出手困难 |
| 在场进攻／防守效率 | 他在场时，球队每100回合得分／失分 | 不是个人每100回合得分／失分；防守失分越低越好，但仍受阵容影响 |
| on/off | 在场与不在场时球队表现的差异，要有两组匹配数据 | v0.4在核验匹配On与Off后支持描述性差值；不能用全队整体代替Off，也不等于个人因果贡献 |
| 终结 | 把进攻机会变成投篮或得分，具体含义随上下文说明 | 不代表一定是自主创造的机会 |
| 发起进攻 | 持球发动配合、带动防守变化 | 不等于每次摸球，也不必然来自高使用率 |
| 二次处理 | 队友先带动防守后，接球继续选择投篮、突破或传球 | 没有回合证据时，不写成已掌握的技术 |
| 空间／投射牵制 | 对手需要照顾外线投手，其他人有更多活动或突破空间 | 仅有命中率不能证明实际牵制强度 |
| 无球价值 | 不持球时，通过投篮、跑位、掩护等帮助进攻 | 本包有限数据不自动证明这些能力全部存在 |
| 战术适配 | 放进这支球队后，承担什么分工、需要谁配合、可能遇到什么问题 | 不等于无条件“完美兼容” |

## 常见改写

“机会转化结果较好” → “得分效率不错”，但要保留样本和基准。
“终结负荷不等于主导创造” → “得分任务多，不代表能把全队进攻都组织好”。
“角色迁移存在不确定性” → “换了球队和分工后，原有表现能否保持，还要再看”。
“防守结果属于共同在场阵容” → “这是场上整套阵容的防守结果，不能全算在他头上”。
“受助攻命中支持无球试验” → “他有靠队友传球得分的记录，可以尝试更多无球分工；效果还需进一步验证”。

改写不做逐词替换。特别是“还没有证明能做到”，不能改成“做不到”。
