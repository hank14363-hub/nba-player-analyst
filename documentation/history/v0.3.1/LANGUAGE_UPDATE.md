# NBA Player Analyst v0.3.1｜表达修改示例

本次仅调整表达、模板与展示标签，保留原有球队配色、图表、数据口径与引用。以下均为合成示例的改写，不是真实球员评价。

| 原表达 | 修改后 |
|---|---|
| 终结产出与组织责任分别评估 | 得分产量和组织水平要分开看。 |
| 受助攻命中支持无球试验 | 他有靠队友传球得分的记录，可以尝试更多无球分工；但效果还需要进一步验证。 |
| 防守结果属于共同在场阵容 | 这是整套阵容的攻防表现，不能全算在他头上。 |
| 得分证据扎实，主控结论仍需保留 | 先用好得分，再看能否带动全队。 |
| 角色要求超出已经证实的传球能力，原有得分结果未必能直接迁移 | 如果让他承担更多组织工作，原有得分表现能否保持，还要再看。 |

## 结论卡片

先发挥得分能力，尝试部分无球分工。能否担任主要组织者，以及防守表现如何，还需要更多比赛资料。

## 术语处理

真实命中率（TS%）第一次出现时，说明它综合考虑两分、三分和罚球的效率；使用率要说明不是持球时间。图表用中文标明得分、助攻和失误，同时保留每75回合的统计尺度。

“还没有足够资料判断防守”，不能改成“防守差”。“值得尝试某种分工”，不能改成“已经证明完美适配”。
