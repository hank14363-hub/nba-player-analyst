# v0.8.7 球评检索阅读流程验证

完整球员研究默认在写作前开展署名球评检索与原文阅读。执行者是使用当前可用搜索/浏览工具的Codex；Python主流程只输出查询建议模板，不自动调用搜索服务。检索围绕本次球员、赛季和研究问题，实际阅读后登记作者、日期、原文链接、样本范围和用途。

## 记录与写作

将实际查询、工具、带时区时间、原文阅读状态与排除理由填写到book_content.commentary_research。complete需有与已核验来源匹配的read记录；limited明确访问或工具限制，skipped明确用户所需研究范围。没有搜索工具可用search_tool_unavailable说明，不编造搜索记录。

采用的观点先写入report.md与claims.json，再通过commentary_cards给出作者观点、本研究回应和验证问题。不能用搜索摘要冒充原文，也不能把作者看片改成自己的录像观察。文章阶段数字不能补入完整赛季统计。
