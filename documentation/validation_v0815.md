# v0.8.15：图片检索流程与计划检查

2026-10-20。针对用户“优化图片检索步骤，尽可能全面”的请求，补全按用途、球员身份、赛季与原作来源的检索方法，并加入离线计划生成与新版实际日志审查。本轮不重新取统计、不改变已有图片/研究册样式、不下载新照片、不声称实际检索了任何外部图库。

## 实现

- references/image_research.md重组为九步：用途、计划、来源、查询扩展、原页核验、失败/停止、GIF/文件、实际记录、验收。覆盖英文/真实别名、跨年与异常赛程、历史球队/转会、人物与事件分类、作者反查、许可索引、机构档案、资料照降级。
- scripts/plan_image_research.py只生成media_search_plan.json/md和media_research.template.json。状态not_executed/pending，查询和候选实际记录为空，联网请求数为0。支持已核对历史球队、别名、目标槽位、可选动图方向；重建不会改实际日志或媒体文件。
- run_analysis新请求标记media_research_protocol=0.2.0并附计划；旧请求不补写新标志。媒体内容0.1.0、统计、book及poster结构不变。
- media_research新协议审查逐用途covered/unavailable/not_needed、采用关联、人工身份/权利/实际画面核对声明和日期/赛季关系；历史/其他活动/日期未知/环境图的disclosure须原文可见。有限缺口标limited，不把环境图作封面。
- 已知Flickr原作尺寸、Commons文件名表示和跟踪URL归并。稳定asset_key供原作标识，跨站同图仍需人工判断，不能声称自动全面识图去重。

## 验证与边界

628项离线标准库回归通过，含33项新增：计划不冒充执行、不推断当前球队、跨年/别名/季后赛/槽位、显式重建不改实际工作、模板不能通过完成审查、未知权利/上传日期/全明星不能冒充本季比赛、资料照限制在caption中、环境封面拒绝、同图填槽拒绝、单图范围/无工具/离线/旧日志兼容与原作去重。

测试使用离线元数据与一个明确标注的单像素测试栅格，不是真实球员照片，不证明当下任何网站可达或许可状态有效。程序只能检查人工核验声明及结构关联，不能证明声明真实、认出球员、确认拍摄日期或替代阅读许可。真实任务仍按原页、实际文件和桌面/手机渲染逐项验收。

格式、发布版本、文档路由、文件摘要及安装记录保存在本轮工作目录。原有统计脚本、视觉资源、历史案例内容保持原值；本轮没有发布到GitHub或覆盖v0.8.14的已发布附件。
